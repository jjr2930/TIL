### Input Mapping Context 만들기
- 원하는 위치(Content/Inputs)에 Input Mapping Context를 만든다. 이름은 IMC_FPS
![[Pasted image 20260629192750.png|472]]
### Input Action 만들기
- 원하는 위치(Content/Inputs)에 Input Action을 만든다. 
	- IA_Look(회전용),: 2d vector
	- IA_Move(움직임용) : 2d vector
	- IA_Aim(조준) : bool

### Input Action을 Mapping Context에 매핑하기
- Input Action은 Mapping Context에서 쓰일 이름과 어떤식으로 인풋의 값을 제공할지에 대한 정보를 가지고 있다.
- Input Mapping Context에 Input Action을 할당한다.
	- Move에는 Keyboard의 WASD를 설정해준다.
	- look 에는 마우스 xy를 지정해주고
	- aim에는 마우스 오른쪽키를 bool로 지정해준다.![[Pasted image 20260629211930.png]]
- 플레이어 블루 프린트를 다음과 같이 적용한다.
![[Pasted image 20260629212754.png]]인핸스드 인풋 시스템을 액터에게 할당해준다.
