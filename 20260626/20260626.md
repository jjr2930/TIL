# 2. C언어
### 프로그래밍 언어란 무엇인가

컴퓨터는 0,1 로 이루어진 언어만 알아듣는다. 즉 명령어도 0과 1로 이루어진 언어로 이야기를 해줘야한다.

`01011100 00011100 0000111000 1111`

하지만 사람이 사용하기엔 난해하다. 이를 보안하기 위해 나온 언어 (좀더 고급언어)가 어셈블리어이다.

`ADD mem1 mem2 mem3`

이 정도도 이전의 이진수보다는 훌륭하지만, 아직 불편하다. 그리하여 나온 언어가  **C**
```
int a = 3
int b = 1
int result =  a + b
```
`

## 작성한 코드는 어떻게 컴퓨터에서 실행이 되는가
- 코드 작성 : 사용자가 코드를 작성한다.
- 전처리 : #define #pragma 등과 같은 전처리 명령어들을 해석하여 코드를 생성한다.
- 컴파일 : 전처리된 코드를 기계어로 번역하는 역할을 한다. 코드 -> 어셈블리어 -> 기계어 결고물은 보통 obj라 불리우는 목적코드를 생성한다.
- 링크: 컴파일 과정을 통해 생성된 목적코드와 목적코드가 참조하는 라이브러리들을 연결하여 최종 실행파일을 생성한다.
- 사용자의 실행명령
- 위의 과정을 빌드라 한다.
## 간단한 출력
컴퓨터는 명령어를 통해 동작한다. 또한 프로그래머는 기본명령어를 조합하여 새로운 명령어를 만들 수 있다. 이렇게 만들어진 명령어를 함수라 부른다.  C에서는 이렇게 새로 사용자가 만든 함수를 헤더파일(.h)에 선언을 해놓는다. 또한 우리들의 선배 프로그래머들은 자주쓰이는 기능(함수)들을  stdio.h라는 파일에 선언해 놓았다. 이러한 미리 만들어준 함수들의 모임을  라이브러리라 한다.

```
include <stdio.h>
int main( int argc, char* arg)
{
	printf("Hello World");
}
```

위의 코드를 실행하면, 콘솔 화면에 Hello World라는 문자가 출력이 된다.

```
include <stdio.h>
int main(int argc, char* arg)
{
	int a = 3;
	int b = 4;
	printf("%d + %d = %d", a, b, a+b)
}
```
이와 같은 코드를 실행하면 '3 + 4 = 7' 라는 화면이 나온다.
%d 이러한 것은 형식 지정자라 하는데 몇가지를 소개하면 아래와 같다.


| 형식지정자 | 의미  | 예시            |
| ----- | --- | ------------- |
| %d    | 정수  | 3             |
| %f    | 실수  | 3.14          |
| %s    | 문자열 | "Hello world" |

## 변수란 무엇인가.
변하는 값을 변수라 한다.
변수의 선언은 메모리를 할당해달라는 요청의 선언이다.
그러면 메모리를 어떻게 사용할지에 대한 정보도 필요한데, 이를 알려주는 것이 데이터 타입이다. 
대표적인 데이터 타입은 아래와 같다.

| 데이터 타입       | 설명        |
| ------------ | --------- |
| int          | 정수형       |
| float        | 부동 소수점 형식 |
| unsigned int | 양수의 정수    |
